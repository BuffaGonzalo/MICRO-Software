# MICRO-Software

**MICRO-Software** es una aplicación moderna desarrollada en **C++** y **QML** sobre el framework **Qt**, diseñada para servir como interfaz gráfica de usuario para el control y monitoreo en tiempo real de un autito de tipo péndulo invertido.

## Resumen del funcionamiento

- Permite la visualización, control y ajuste remoto de parámetros del sistema embebido del autito, comunicándose mediante una interfaz serial.
- Presenta interfaces gráficas intuitivas pensadas para ofrecer una experiencia de usuario fluida y moderna.
- Visualiza datos en tiempo real a través de gráficos claros y controles accesibles.
- Facilita la configuración del sistema, telemetría y diagnóstico rápido del autito.

## Características principales

- Lógica principal optimizada para comunicación eficiente con el firmware.
- Interfaz gráfica atractiva y responsiva.
- Arquitectura modular, adaptable y expansible.

## Firmware complementario

Para el control en tiempo real del autito, este software se complementa con el proyecto [MICRO-Firmware](https://github.com/BuffaGonzalo/MICRO-Firmware/tree/master), que ejecuta el control y la lógica embebida en la placa física.
